## Rollback

- Code: redeploy the previous Pages deployment and Worker version. The Worker must stay on this release (or newer)
  while any note or verification flag exists, otherwise an older Worker's `normalizeDoc` keeps them but its UI ignores
  them (no data loss either way).
- Data: the change is ordinary planner ops; undo by applying the inverse ops (each `setSlot` back to its `expect`,
  `removeCustomTool` for the ten new items, `setNote` with empty text, `setUnverified` null, `deleteBundle`), never by
  restoring an old D1 snapshot over newer edits. Main images: "restore previous" per compartment (each keeps its
  previous main for one-tap recovery).
